An end-to-end **Data Science Capstone Project** that analyzes the Indian job market using data scraped from **Naukri.com**. The project combines **Web Scraping**, **Data Cleaning**, **Exploratory Data Analysis (EDA)**, **Machine Learning**, and **Power BI** to uncover hiring trends, salary insights, and skill demand across various job roles.

> 🎥 **Includes detailed walkthrough videos explaining the complete project workflow, EDA, machine learning model, and Power BI dashboard.**

---

# 📖 Project Overview

Understanding the current job market is essential for job seekers, recruiters, and organizations. This project collects job listing data from Naukri.com, processes it using Python, performs exploratory data analysis, builds a machine learning model for salary prediction, and presents business insights through an interactive Power BI dashboard.

The project demonstrates the complete lifecycle of a real-world data science project—from raw data collection to predictive analytics and visualization.

# 📈 Key Insights

- Software Engineer and Data Scientist roles dominate hiring.
- Python, SQL, and Machine Learning are among the most demanded skills.
- Bengaluru, Hyderabad, and Pune are major hiring hubs.
- Higher experience generally corresponds to higher salary ranges.
- Company ratings show only a moderate relationship with review counts.
- Hiring activity varies based on job posting recency.
- Machine learning successfully predicts salary using multiple job-related features.
